# Evaluation datasets

Large dataset files are intentionally not stored in this source project. The
evaluated working copy is on Orin Nano and the durable backup is on Spark.

- `gmdcsa24/`: Subjects 1–4 videos and CSV annotations.
- `realbiomfall/`: prepared RealBiomFall clips and upstream labels.
- `realbiomfall-manifest.json`: frozen 34-clip external testing manifest.

See [`../ASSET_LOCATIONS.md`](../ASSET_LOCATIONS.md) for exact paths, public
download sources, preparation commands and backup verification. Consult and
comply with each upstream dataset's license before redistribution.
