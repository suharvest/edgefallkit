# EdgeFallKit 0.1.0-rc1

This first release candidate delivers a common multi-stream, multi-person fall
detection stack for Jetson Orin Nano/NX, RK3576/RK3588, Raspberry Pi 5 with
Hailo-8, reCamera SG2002, and reCamera Pro.

## Highlights

- Common reCamera-compatible MQTT v1 result contract across all platforms.
- Independent tracker, temporal MLP, and fall state for every person.
- Hardware-accelerated RTSP paths and native pose postprocessing.
- Published model-free ARM64 runtime images for Jetson, RKNN, and Hailo.
- Explicit-license, cache-aware model download and target conversion helpers.
- Frozen GMDCSA Subject 4 results and reproducible device performance reports.

## Published runtime images

Immutable image references and digests are recorded in
[`0.1.0-rc1.json`](0.1.0-rc1.json). All pose models remain external and retain
their upstream license terms.

## Scope and limitations

- This is an engineering release candidate, not a medical or emergency-response
  certification.
- reCamera Pro native temporal accuracy still requires an RV1126B target.
- RK3576, RK3588, and Hailo-8 have not yet been evaluated on RealBiomFall.
- The RK official-weight conversion path is covered by automated dry-run,
  provenance, cache, and deployment tests; the heavyweight upstream download
  and conversion is intentionally not bundled into CI.
